1) Procedural : Step by step instructions useful for script and automation

Important os Module Commands

| Command  | Purpose | Example |
| --- | --- | --- |
| `os.getcwd()` | Returns the current working directory | `os.getcwd()` |
| `os.listdir()` | Lists files and folders in a directory | `os.listdir()` |
| `os.mkdir()` | Creates a single directory | `os.mkdir("myfolder")` |
| `os.makedirs()` | Creates directories and subdirectories | `os.makedirs("folder1/folder2")` |
| `os.rename()` | Renames a file or directory | `os.rename("old", "new")` |
| `os.remove()` | Deletes a file | `os.remove("file.txt")` |
| `os.rmdir()` | Deletes an empty directory | `os.rmdir("myfolder")` |
| `os.path.exists()` | Checks whether a file or directory exists | `os.path.exists("myfolder")` |
| `os.path.isfile()` | Checks whether the path is a file | `os.path.isfile("file.txt")` |
| `os.path.isdir()` | Checks whether the path is a directory | `os.path.isdir("myfolder")` |
| `os.path.join()` | Joins two or more paths | `os.path.join("folder", "file.txt")` |
| `os.environ` | Accesses environment variables | `os.environ["PATH"]` |
